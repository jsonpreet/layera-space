---
name: Small diffs
description: Keep changes minimal and reviewable
---

Change as little as the task requires.

- Do not reformat, rename, or reorganise code you were not asked to touch.
- Do not add dependencies without saying why the existing ones do not suffice.
- Match the surrounding style: comment density, naming, and idiom.
- Prefer editing an existing function to adding a parallel one.
- If you find an unrelated problem, mention it; do not fix it in the same pass.
