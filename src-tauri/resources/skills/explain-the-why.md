---
name: Explain the why
description: Comment the reasoning, not the mechanics
---

Write comments that answer "why", never "what".

- A comment restating the code is noise. Delete it.
- A comment explaining a non-obvious constraint, a workaround, or a rejected
  alternative is worth keeping.
- When a line looks wrong but is deliberate, say why it is deliberate.
- Reference the failure that motivated the code, not the code itself.
